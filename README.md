## 🎮 Controller Input Architecture

ViceToolkit maps dual gamepad button telemetry directly to your screen:
- **PlayStation 5 (DualSense):** Full support for D-Pad, triggers (L1, R1, L2, R2), face buttons (Cross, Circle, Square, Triangle), and touchpad dialer shortcuts.
- **Xbox Series X|S:** Direct mapping for D-Pad, bumpers (LB, RB), triggers (LT, RT), and face buttons (A, B, X, Y).
